# Apetit — DESIGN.md
> Витрина фастфуда на тёплой кремовой бумаге. Еда стоит на фоне одна, без рамок. Над ней — огромное слово категории, как вывеска. Один жёлтый — цена и кнопка. Тонкие чёрные линии, рисованные штрихи вместо иконок, продукт живёт при скролле.

**Тема:** светлая · **Главный экран:** телефон 390 px, десктоп — та же система шире
**Версия:** 2.5 · 22.09.2026 · утверждено по макетам docs/mock-*.png · собрана по референсам Амяна (см. ниже) + бренд Apetit из PSD меню

Apetit — фастфуд, и еда должна выглядеть так, чтобы хотелось есть. Поэтому фото
блюд — единственный декор. Всё остальное отступает: тёплый кремовый фон вместо
белого, тонкие линии вместо рамок и теней, одна жёлтая краска для денег и
действий. Заголовки — узкий плотный Oswald заглавными, во всю ширину, как в
печатном меню; названия и цены — Manrope; текст — Montserrat. Немного характера:
иконки категорий нарисованы одной линией от руки, а не взяты из набора. Если
элемент не помогает выбрать блюдо — его нет.

### Glass (ровно три места: шапка, корзина снизу, оверлей смены города)

```
background: rgba(250, 247, 242, 0.78);
backdrop-filter: blur(16px) saturate(130%);
-webkit-backdrop-filter: blur(16px) saturate(130%);
border-bottom: 1px solid #1A1714;   /* шапка: линия, не тень */
```
Fallback: `background: rgba(250,247,242,0.96)`. Нигде больше.
Цифры в примере — для фона A. На деле цвет берётся из фона страницы:
переменные `--glass-bg` и `--glass-bg-fallback` ставит корневой layout
(см. Surfaces), поэтому при смене фона шапка и корзина меняются вместе с ним.

### Background — живые контурные линии бренда
Фон — Cream (цвет из `motion.json`, см. Surfaces) + слой контурных линий
(как на меню-экранах в точках).
Картинки больше нет: линии рисует движок анимаций (см. Motion) — слой
`src/motion/layers/contours.ts` на общем холсте WebGL. Линии — это «горизонтали»
поля из десяти волн с разными направлениями и скоростями; толщина берётся из
производной поля, поэтому она одинаковая при любом масштабе и не пикселит.

Значения — `src/config/motion.json`, раздел `background`. Меняются в панели
`/dev/motion` (только разработка), не в коде:

| Настройка | Значение | Что это |
|---|---|---|
| `mode` | `live` | «Живые линии»; `static` — один неподвижный кадр |
| `tilesAcross` | 2.11 | плотность: сколько раз рисунок укладывается по ширине экрана |
| `width` | 0.8 | толщина линии |
| `opacity` | 0.45 | насыщенность |
| `speed` | 0.35 | скорость жизни линий |
| `parallax` | 1.2 | сдвиг при прокрутке, доля от прокрутки |
| `ease` | 0.1 | инертность общего сглаживания прокрутки |
| `color` | `ash` | Ash `#A79E95` · Smoke `#7A716A` · Sand `#EAE2D5` |

- **Масштаб от ширины экрана.** Размер клетки узора не в CSS-пикселях, а
  долей экрана: `uScale = ширина холста в пикселях экрана / tilesAcross`,
  пересчитывается каждый кадр — поворот телефона и смена размера окна
  учтены. Поэтому на телефоне 390 px рисунок такой же плотный, как на
  компьютере, а не втрое крупнее. Значение 2.11 = прежние 900 px на клетку
  при ширине экрана 1900 px: вид на компьютере не изменился.
  Толщина линии (`width`) остаётся в пикселях экрана и от масштаба не
  зависит — она берётся из производной поля (`fwidth`).
- **Цвет фона под линиями** — `page.background` из того же файла (см.
  Surfaces).
- **Слой:** экран городов, меню, оформление, правовые страницы. Холст
  `position: fixed`, под всем контентом (z-index −1), `pointer-events: none`,
  высотой `100lvh` (при прятанье адресной строки размер не меняется и рисунок
  не дёргается). Появляется после показа страницы и проявляется за 300 мс.
- **Движение:** линии медленно перетекают сами; при прокрутке слой едет на
  `parallax` × сглаженную прокрутку. Движок стоит, когда открыт лист блюда или
  корзина, спрятана вкладка, страница сама едет к категории.
- **«Уменьшить движение»:** один неподвижный кадр, цикл выключен (t = 0,
  прокрутка = 0).

Никаких других пятен, градиентов, текстур. Видео `assets/brand/linii-fundal.mp4`
остаётся только образцом рисунка — на сайте оно не используется.

## Components

### City Screen — витрина (Franky's)
Экран без шапки и подвала. Шесть плиток столбиком, зазор 12px, внутри 16px
отступа от краёв. Плитка: без заливки, рамка `rule` 1px Ink, 16px radius, высота
88px, город Oswald 44px caps Ink по центру. Больше ничего внутри. Нажатие:
плитка заливается Ink, текст Cream, 150ms, затем раскрывается в меню.
Десктоп: сетка 3×2, плитки 200px высотой. Логотипа нет — решено.

### Header — стекло + линия
56px, sticky, glass, снизу `rule`. Слева логотип APETIT (SVG, высота 22px, Ink).
Справа: город Manrope 600 15px + рисованная стрелка вниз (сменить город), и RO/RU
13px Smoke. По центру пусто.

### Category Chips — с рисованными иконками
Горизонтальная лента под шапкой (высота ленты 46px), sticky вместе с ней, фон
glass. Чип: рисованная иконка категории 16px + название Manrope 600 13px, высота
32px, 9999px, padding 0 12px 0 9px, зазор 8px. Неактивный: без заливки, рамка
`rule`. Активный: Ink fill, Cream текст и иконка. Не жёлтый.
Нажатие на чип (Амян): иконка в чипе делает **один оборот** (rotate 360°) за
**250ms**, `--ease-out`; одновременно чип заливается Ink и страница плавно едет
к секции. Один раз на нажатие, не в цикле; повторное нажатие во время оборота
его не перезапускает. Enter и Space — то же, что нажатие. При reduced-motion —
только смена заливки, переход без плавности.
Пока страница едет к выбранной категории, активным остаётся её чип —
промежуточные категории по дороге не загораются. Если человек сам прервал
прокрутку (колесо, касание), активна категория, где страница остановилась.

## Motion

| Token | Value |
|-------|-------|
| `--ease-out` | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| `--dur-fast` | 150ms — нажатия, переключатели |
| `--dur-base` | 240ms — появление плиток, чипы, лист |
| `--dur-slow` | 420ms — экран городов, переход в меню |

#### Движок анимаций — `src/motion`
Все эффекты на холсте живут в одном движке: один `<canvas>` на весь экран, один
контекст WebGL2 (запас — WebGL1 + `OES_standard_derivatives`; нет ни того, ни
другого — движок просто выключен, сайт работает), один цикл кадров. Эффект —
это слой: `{ id, zIndex, init(gl), render(gl, frame), dispose(gl) }`; слой
владеет своими буферами и шейдерами. Сейчас слой один — фон (Background).

- **Кадр** даёт слоям `{ t, dt, width, height, dpr, scroll }`. `scroll` —
  общая сглаженная прокрутка: `k = 1 − (1 − ease)^(dt/16.67)`,
  `smooth += (target − smooth) × k`. Слой сам умножает её на свой `parallax`,
  поэтому все слои двигаются согласованно.
- **Качество — четыре уровня:** 1) плотность пикселей до 1.5 · 2) плотность 1.0
  · 3) 30 кадров/с · 4) стоп, один кадр. Первые две секунды движок считает
  кадры: меньше 50 — уровень ниже, ещё раз меньше 50 — ещё ниже, меньше 40 —
  стоп. Уровень запоминается на время визита (sessionStorage) и сам не
  повышается.
- **Паузы по причинам:** цикл идёт, только когда причин нет. Встроены: вкладка
  спрятана, открыт лист блюда, открыта корзина, страница сама едет к категории.
  Тяжёлые эффекты не работают одновременно: слой берёт паузу для остальных
  (`engine.pause('hero')`).
- **Загрузка:** движок подключается после показа страницы (dynamic import,
  `ssr:false`), на скорость первого экрана не влияет; холст проявляется за
  300 мс (`--dur-canvas`).
- **Настройка:** `src/config/motion.json` по разделу на эффект; панель
  `/dev/motion` — ползунки слева, настоящая страница меню справа, «Сохранить»
  переписывает файл. Панель существует только в разработке.

Фаза 1 (в первой версии сайта):
- Мягкий скролл: Lenis, только на десктопе (≥1024px). На телефоне — нативный,
  он и так плавный, а Lenis там ест батарею.
- Вход: плитки городов появляются снизу (y 24→0, opacity) с задержкой 60ms
  друг за другом. Выбранная заливается Ink и раскрывается в меню.
- Слово-вывеска категории: при появлении в кадре выезжает снизу из-под маски
  (clip-path), 420ms. Один раз.
- Плитки блюд: при появлении в кадре, y 12→0 + opacity, по строкам, 40ms
  задержка. Один раз.
- Фото блюд: лёгкий параллакс ±6px, только transform, только десктоп.
- Лист: снизу 240ms, фон затемняется до rgba(26,23,20,.35).
- Всё через transform/opacity/clip-path. Никогда top/left/height/filter/box-shadow.
- `prefers-reduced-motion: reduce` → длительности 0, параллакс и Lenis выключены.
- Элементы интерфейса (иконки, индикаторы, кнопки) не анимируются бесконечно.
  Фоновые слои движка `src/motion` — исключение: они обязаны останавливаться
  при скрытой вкладке, открытом листе/корзине, тяжёлой анимации и при
  `prefers-reduced-motion`.
- Ничего не всплывает само, нет автокаруселей.

Фаза 2 (после запуска — «штучки», Hungry Tiger / Franky's):
- Витрина города: один продукт-герой (например, Kebab Cheese) над меню. При
  скролле растёт с 60vh и наклоняется на ~50°, слово APETIT за ним уходит вверх
  медленнее (пиннед-секция, GSAP ScrollTrigger scrub). Кадры: 48–72 штук из
  AI-видео (Kling/Higgsfield: «slow rotation, white background, static camera»)
  или съёмки на вращающемся столике. Формат — WebP-секвенция на canvas.
  Загружается лениво, только после меню; на слабых устройствах — статичное фото
  с 2D-ростом (scale 0.8→1, transform).
- Одно такое место на сайте. Не на каждое блюдо.

## Do's and Don'ts

### Do
- Фон — ровный Cream везде. Никаких тёмных секций, цветных полос, белого `#FFFFFF`.
- Еда стоит на фоне одна: без карточки, без рамки, без тени — только лужица.
- Слово категории — огромное, во всю ширину, продукты наезжают на него.
- Жёлтый только как заливка: цена, «+», Primary, активный размер.
- Линии — тонкие, чёрные, настоящие. Разделители точечные.
- Иконки категорий — наши, рисованные одной линией. Функциональные — Lucide.
- Кнопки и чипы — 9999px. Радиусов ровно четыре.
- Стекло — три места. Скролл 60 fps на дешёвом Android — проверять.
- Экран городов — шесть плиток и ничего больше.

### Don't
- Не использовать жёлтый как текст, рамку, градиент, фон секции.
- Не добавлять второй акцент. Не красить акции в красный.
- Не класть еду в карточки с заливкой и тенью. Не ставить box-shadow на плитки, кнопки, чипы, шапку.
- Не ставить Oswald на текст, кнопки, цены.
- Не делать тёмных секций, «hero» с фото во весь экран, цветных полос.
- Не использовать эмодзи, иконки в кружочках, стоковые иллюстрации, «три карточки
  с преимуществами», фиолетовые/синие градиенты, glow, шахматку, засечки.
- Не показывать «Lorem ipsum», «Image coming soon», заглушки-тексты.
- Не анимировать box-shadow, filter, height. Ничего бесконечного.
- Не ставить всплывающие окна, cookie-плашки, баннеры про приложение, чат-виджеты.
- Не сжимать боковой отступ меньше 16px.
