# MOTION.md — закон движения сайта Apetit

Этот файл — источник правды по любому движению на сайте: анимации, переходы,
эффекты прокрутки, заставки, фон. Перед любой задачей, где что-то двигается,
читать этот файл целиком. Если задача противоречит ему — остановиться и сказать,
не решать «как лучше».

Цель простая: сайт должен ощущаться спокойным и дорогим. Не «много анимаций»,
а «каждое движение на своём месте». Ориентир — как сделано у Apple: в каждый
момент ведёт что-то одно, всё остальное замирает и не мешает.

---

## 1. Главное правило: одна ведущая вещь

В каждый момент времени у пользователя есть **одна** вещь, которая движется
и держит внимание. Всё остальное в этот момент неподвижно.

Приоритет (старший гасит младших):

1. **Заставка категории** (splash) — пока идёт, всё под ней стоит.
2. **Шторка товара** (открытие/закрытие).
3. **Корзина** (открытие/закрытие, изменение количества).
4. **Эффекты прокрутки** (карточки товаров, фон).

Когда включается старший уровень — младшие обязаны мгновенно вернуться в покой:
`lift = 0`, трансформы сняты, `will-change` убран. Не «плавно затухнуть»
параллельно, а именно уступить. Это и есть разница между порядком и хаосом.

Движок (`src/motion/`) уже умеет паузы по причинам (`hidden`, `sheet`, `cart`,
`scroll`, `hero`) — любой новый эффект обязан подписаться на эти паузы, а не
жить своей жизнью.

## 2. Длительности

Только эти значения. Между ними ничего не придумывать.

| Значение | Для чего |
|---|---|
| **120 мс** | Мгновенный отклик: нажатие кнопки, +/− количества, чип категории |
| **200 мс** | Мелкое изменение состояния: цвет, подсветка, появление подписи |
| **320 мс** | Появление элемента, скрытие элемента — основная рабочая величина |

Если при подборе на глаз получилось значение рядом со шкалой (340, 360) —
округляем к ближайшему из таблицы. Разница в 40 мс не видна, а единая шкала
видна сразу: без неё через месяц на сайте будет двенадцать разных длительностей.
| **500 мс** | Крупное: шторка товара, корзина, смена экрана |
| **900 мс** | Только заставка категории (полноэкранная) |

Закрытие всегда быстрее открытия примерно на треть (500 → 320). Уходить всегда
легче, чем приходить.

Задержки (stagger): шаг **70 мс**, не больше **трёх** шагов подряд. Четвёртая
карточка в ряду появляется вместе с третьей. Длинные каскады выглядят дёшево.

## 3. Кривые

Две на весь сайт:

- **Вход, появление, подъём:** `cubic-bezier(.22, 1, .36, 1)`
  (быстро стартует, долго успокаивается — то самое «дорогое» ощущение)
- **Уход, перемещение, закрытие:** `cubic-bezier(.4, 0, .2, 1)`

Третьего варианта нет. `linear` — только для бесконечно-равномерных вещей
(вращение продукта в видео-заставке). `ease`, `ease-in-out` по умолчанию —
запрещены, они читаются как «ничего не настраивали».

**Пружина** — только там, где движение вызвано пальцем пользователя
(эффект прокрутки карточек). Формула одна:

```
stiff = (растём ? 320 : settle)   // settle — из motion.json, по умолчанию 130
damp  = 2 * sqrt(stiff)           // критическое затухание, без дрожи
```

Перелёт (overshoot) допускается не больше **1.5 %** и только на масштабе.
Никаких «пружинок» с отскоком — это ощущается как игрушка, а не как еда.

## 4. Что вообще имеет право двигаться

Анимировать разрешено **только** `transform` и `opacity`. Всё остальное
(`width`, `height`, `top`, `left`, `margin`, `filter`, `box-shadow`) —
запрещено: это дёргает раскладку и роняет кадры на телефоне.

Тени делаем эллипсами `radial-gradient` и меняем им `transform`/`opacity`.
`filter: blur()` в анимации — запрещён.

На один элемент одновременно **не больше двух** анимируемых свойств.
Например: `transform` + `opacity`. Не три.

**Никогда не двигаются:**

- цена и кнопка «+» (по ним целятся пальцем — движущаяся цель раздражает);
- текст названия и состава (параллакс на тексте читается как дешёвый шаблон);
- шапка и чипы категорий;
- вообще ничего по бесконечному циклу — на сайте нет ни одного объекта,
  который крутится, пульсирует или мигает сам по себе.

## 5. Покой

Сайт в покое — по-настоящему неподвижен.

- Через **400 мс** после остановки прокрутки все эффекты прокрутки обязаны
  выйти в ноль и **остановить** `requestAnimationFrame`. Не «крутиться вхолостую».
- Загруженная страница показывается **в покое**: то, что видно сразу, не
  анимируется. Анимация появления — только для того, что въезжает в экран
  впервые при прокрутке. Это же условие держит LCP и CLS = 0.
- После смены категории карточки, которые видны сразу, тоже не анимируются:
  движение там уже было — заставка.

---

## 6. Уважение к пользователю

- `prefers-reduced-motion: reduce` → все эффекты прокрутки выключены, появление
  сводится к `opacity` за 180 мс, заставка категории показывается статичным
  кадром. Это не «ухудшенная версия», это равноценная.
- Самый низкий уровень качества движка (по FPS) → эффекты прокрутки
  выключаются, появление и тени остаются.
- Заставку всегда можно прервать касанием.
- Ничего не мигает чаще трёх раз в секунду.

---

## 7. Производительность

- Цель: **60 fps на среднем Android**, не на компьютере разработчика.
- Кадр эффекта прокрутки обновляет только карточки в пределах экрана ±200 px.
- `will-change` ставится на время движения и снимается в покое.
- Никакого React-состояния на каждый кадр: только прямая запись в
  `element.style.transform` из слоя движка.
- Порог Lighthouse на мобильном — тот, что записан в SPEC.md (сейчас 85); SPEC
  старше этого файла. Дополнительное условие: после задачи с анимацией балл не
  ниже, чем был до неё. CLS = 0 всегда.

---

## 8. Настройки

У каждого эффекта — своя секция в `src/config/motion.json`, своя zod-схема и
своя вкладка в `/dev/motion` с кнопкой «Copiază». Правило без исключений:
**нет настройки — нет эффекта**. Цифры не зашиваются в код, чтобы хозяин мог
подобрать ощущение сам, а не через новую задачу.

---

## 9. Проверка перед тем, как считать задачу готовой

1. Прокрутить меню вверх-вниз пальцем на телефоне: ничего не дёргается,
   ничего не догоняет с опозданием, текст не плывёт.
2. Быстро листнуть и резко остановиться: карточки садятся мягко, без дрожи.
3. Нажать категорию во время прокрутки: эффекты прокрутки мгновенно замерли,
   ведёт заставка.
4. Открыть товар, закрыть, открыть корзину: под шторкой ничего не шевелится.
5. Включить «уменьшить движение» в системе: сайт полностью спокоен.
6. Прогнать `review-animations`, затем Lighthouse на мобильном.

Если хоть один пункт не выполняется — задача не готова, даже если тесты зелёные.
