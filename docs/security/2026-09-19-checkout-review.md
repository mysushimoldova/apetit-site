## Путь данных

Браузер → `submitOrderAction(input: unknown)` (Next 16 сверяет Origin с Host —
CSRF) → `OrderInputSchema` (`strictObject`: лишние поля вроде `total` — отказ;
длины, 1–50 позиций, qty 1–99, телефон → +373…, запрет управляющих символов) →
ловушка → точка есть / не на паузе → часы по Europe/Chisinau → каждая позиция
по каталогу точки (`priceLine`) → повтор за 2 мин → лимиты → номер → снимок.
Клиенту уходит снимок без имени, телефона и адреса. В лог — номер заказа,
точка, сумма, маска телефона `+373 67 *** 222`.
