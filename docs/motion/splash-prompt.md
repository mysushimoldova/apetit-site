Задача: заставка категории (splash) — главный эффект сайта. Одна цельная система:
слой в motion-движке + секция в motion.json + вкладка в /dev/motion.

Прочитай: docs/MOTION.md (он старше скиллов), docs/motion/splash-demo.html
(эталон поведения — логика в <script>: playSplash, endSplash, keyFrame, switchNext,
layout; в шапке файла описан формат роликов и шейдер), SPEC.md разделы 5–6,
DESIGN.md, PROGRESS.md, src/motion/*.

ЧТО ЭТО
При нажатии на чип категории на весь экран меню играет заставка ~1 секунду: на
кремовом фоне с линиями — жёлтый круг, над ним крупно вращается настоящее блюдо
этой категории, поверх — контурное слово категории. Потом заставка уходит шторкой
вверх и открывается сетка товаров. Тени под блюдом нет — ни в видео, ни нарисованной.

ВИДЕО (уже в проекте, не пересоздавать; сделаны scripts/splash-video/make.py)
public/splash/<slug>.mp4 — 17 файлов, h264, 60 к/с, ровно 1.5 с (90 кадров).
Формат кадра особый: ВЕРХНЯЯ половина — цвет, НИЖНЯЯ — маска (альфа) того же
кадра; высота файла вдвое больше видимой. Маска посчитана нейросетью: фон и тень
убраны, внутри силуэта продукт сплошной. Разгон и замедление вшиты в файл, все
ролики крутятся в одну сторону. В цветной половине внизу слева два квадрата 16×16:
чёрный (x 0..16) и белый (x 16..32) — эталоны для шейдера (см. ниже).
Соответствие категория → слоги (в порядке показа):
  kebab: kebab-xl-xxl, kebab-cheese
  burgers: cheeseburger-dublu-vita, hamburger-dublu-vita
  gozleme: gozleme-carne, gozleme-mozzarella
  sandwich: sandwich-salam, sandwich-sunca
  salad: salata-cezar, salata-greceasca
  supe: supa-bostan, supa-spanac
  drinks: cola, fanta
  desert: brinzoaice
  sosuri: sos-ketchup, sos-usturoi
Категории без видео (menu, crispy, hot-dog, pizza, cartofi и любые будущие) —
заставки нет, переход обычный. Список брать из данных, не из хардкода: нет файла —
нет заставки, без ошибок в консоли. Показывать только блюда, доступные в выбранной
точке: если первого нет в меню точки — берётся второе; если ни одного — заставки нет.

РИСОВАНИЕ
Слой "splash" в src/motion (WebGL2, тот же контекст движка, отдельная программа).
Шейдер — ровно как KFS в эталоне:
  - цвет = texture(uv.x, uv.y*0.5), маска = texture(uv.x, 0.5+uv.y*0.5).r;
  - калибровка: lo = texelFetch(8, hh-8).r, hi = texelFetch(24, hh-8).r, где hh —
    половина высоты текстуры; k = 1/max(hi-lo, 0.25); цвет и маска = (x - lo)*k;
    (часть браузеров отдаёт видео в WebGL сжатым до 16..235 — эталоны это снимают);
  - маска = smoothstep(0.12, 0.94, маска) — отсекает шум сжатия вокруг продукта;
  - на выходе премультиплицированный цвет, blend ONE / ONE_MINUS_SRC_ALPHA, как в фоне.
По умолчанию одно блюдо на категорию (count = 1). Если в настройках 2 — второе
НЕ растворяется, а подменяет первое непрозрачно (см. функцию scaled() и main() в
эталоне): второе поверх первого, первое уменьшается (1 → 0), второе растёт
(0.86 → 1), оба ролика стартуют с нуля вместе и идут синхронно, никаких перемоток.
playbackRate = clamp(1500 / hold, 0.5, 2) — разгон уже внутри файла.
Размер блюда — по формуле layout() эталона (вписать по ширине и высоте с учётом
пропорций: вертикальные бутылки и горизонтальные сэндвичи одинаково крупные).
Слово категории, жёлтый круг, линии — как в эталоне, слово поверх блюда.
Нет WebGL2 → заставки нет, сразу сетка. Потеря контекста (webglcontextlost) →
заставка мгновенно закрывается, сетка на месте.

ПОВЕДЕНИЕ
- Играет каждый раз при выборе категории, в том числе повторно.
- Прерывается касанием в любой момент — сразу уход.
- Уход: шторка вверх (exit "lift"), длительность из настроек.
- Пока играет: остальные эффекты движка (фон, подъём карточек) на паузе (причина
  'splash' в pause.ts); после ухода сетка уже в покое — появление карточек не
  проигрывается (это движение уже было).
- Скролл меню заблокирован на время заставки, после — сброшен наверх.
- Кнопка «назад» браузера во время заставки закрывает её, а не уходит со страницы.
- prefers-reduced-motion → заставки нет совсем.
- Уровень качества 1 (самый низкий по FPS) → заставки нет.
- Экономия трафика (navigator.connection.saveData или effectiveType 2g/slow-2g) → нет.

ЗАГРУЗКА
Ролики НЕ грузятся при открытии сайта. Первое нажатие на категорию: если файл ещё
не загружен — заставка не играет (обычный переход), а ролики этой категории
грузятся в фоне для следующего раза. Загруженное держать в памяти на время сессии.
Никаких <link preload>. Заголовки кеша для /splash/*.mp4 — год, immutable.

НАСТРОЙКИ
motion.json → "splash": { "enabled": true, "hold": 1500, "fade": 200, "zoom": 0.83,
"wordY": -5, "wordTop": true, "disc": 0.62, "lines": 0.35, "count": 1, "xfade": 180,
"exit": "lift", "skip": true }. zod-схема как у остальных секций.
Вкладка «Ecran categorie» в /dev/motion с теми же ползунками, что в эталоне,
кнопками «Проиграть» и «Copiază». Все значения только оттуда, в коде — ни одного числа.
Хозяин подберёт значения сам на телефоне после внедрения.
